## 1. 소개

> "오늘 뭐 했지? 뭐 해야 하지? 얼마 썼지?"를 **한 화면에서** 답하는 개인 기록장.

예전에 만든 단일 파일 달력·가계부 [달빛달력](https://github.com/Crowtit517/moonlight_calendar)에서 출발했습니다. 여기에 "My Tasks" 스타일의 할 일 관리를 더하고, 여러 기기에서 쓸 수 있도록 다시 설계했습니다.

| 이런 분께 | 담다가 하는 일 |
|---|---|
| 달력, 할 일, 가계부 앱을 따로 쓰기 번거로운 분 | 날짜 하나를 누르면 그날 일정·할 일·지출이 한 번에 |
| 내 기록이 남의 서버에 쌓이는 게 싫은 분 | **운영 서버가 없습니다.** 기록은 내 기기와 내 구글 드라이브에만 |
| 은행·카드 연동이 불안한 분 | 금액·날짜·메모만 직접 적습니다. **금융 연동 코드 없음** |
| 앱 사용이 익숙하지 않은 분, 어린이 | 그림으로 설명하는 사용 가이드, 부드러운 화면 |

## 2. 주요 기능

### 📅 캘린더 + 하루 패널
- 한 달을 훑어보고, 날짜를 누르면 **하루 패널**이 스르륵 열립니다 (PC는 옆, 폰은 아래에서).
- 패널에서 할 일 체크, 그날 지출 요약, 일정 추가·고치기를 한 번에.
- **💰 금액 보기 스위치**: 옆에 사람이 있을 때 한 번 누르면 달력과 패널의 금액이 모두 숨겨집니다.

### 💻 PC 앱 + 바탕화면 위젯
- 설치 파일 한 번이면 끝, 바탕화면에 **"담다"** 바로가기. 창 전체를 쓰는 화면: 캘린더는 왼쪽, 오른쪽 구역은 **[이 날 · 할 일 · 가계부]** 탭 (끌어서 창의 1/3까지 넓힘).
- **바탕화면 위젯**: 다른 창 뒤, 바탕화면에 깔리는 반투명 달력. 날짜를 눌러 바로 체크·추가하고, **[오늘 요약]**으로 하루만 볼 수 있습니다. 위젯에서 고치면 담다에 바로 반영됩니다.
- 창을 닫으면 쓰던 글자까지 저장하고 끝납니다. 켤 때는 **"담다 · 하루를 담는 기록장"** 시작 화면이 스르륵 나왔다 사라집니다(폰에서도 홈 화면 앱으로 열면). 폰·웹 화면은 그대로입니다.

<img src="docs/images/11-pc-app.png" alt="담다 PC 앱 (다크 모드): 왼쪽 캘린더, 오른쪽 이 날 탭" width="860">

### 📱 갤럭시 앱 + 알림
- APK로 설치하는 **갤럭시 담다 앱**. 폰의 구글 계정을 고르면 연결되고, 로그인이 계속 유지됩니다.
- 할 일·반복 할 일에 **⏰ 알림 시간**을 정하면 **앱을 꺼도, 인터넷이 없어도** 폰 알람으로 울립니다 ("아침 9시 약 먹기"). 구글 캘린더 일정은 폰의 캘린더 앱이 알려 주니 두 번 울리지 않습니다.

### 🔄 구글 캘린더 자동 양방향 동기화
- **구글 계정을 연결하면 캘린더도 함께.** 갤럭시(삼성)·구글·노션 캘린더의 일정이 담다 달력에 보이고, 담다에서 **추가·수정·삭제**한 일정이 폰 캘린더에도 반영됩니다.
- **일정만 주고받습니다.** 할 일과 가계부는 담다에만 있어서 폰 캘린더가 지저분해지지 않고, 돈 정보가 공유 캘린더로 새지 않습니다.
- 일정에 **알림**(10분 전 ~ 하루 전)을 붙이면 구글 캘린더가 PC와 폰에 알려 줍니다.
- **여러 구글 계정**(개인 · 회사 · 학교)의 캘린더를 함께 볼 수 있습니다. 추가 계정은 메뉴에서 "다른 계정 N개 ▾"로 접혀 있습니다.
- 연결 전에 담다에만 적어 둔 일정은 **저절로** 구글 캘린더로 옮겨집니다.
- 안전장치: 인터넷이 끊겨도 먼저 화면에 보이고 나중에 보냄 · 다시 보내도 **하나만** 생김 · 폰에서 먼저 고친 일정은 **덮어쓰지 않음** · 지우기는 8초 되돌리기 · 반복 일정·공휴일·공유 캘린더는 보기만.

### ✅ 할 일
- 카테고리별 진행률, 필터, 밀린 할 일 한 번에 가져오기.
- **반복 할 일**: 매일 · 요일 선택 · 매월, 하루 1~3번(아침·점심·저녁), 반복 또는 기한(시작 ~ 끝).
- **🔥 연속 기록**으로 꾸준함을 눈으로 확인. 지울 때는 "이 날만 / 이 날부터 앞으로 전부".

### 💰 가계부
- 월·연 통계, **지난 기간 같은 시점과 비교**하는 누적 그래프, 카테고리별 지출.
- **고정 수입·지출**: 월급·월세·통신비를 한 번 등록하면 그날 자동 기록. 금액이 매달 다른 항목(전기요금)은 그날 금액을 물어봅니다.
- 이번 달 남은 고정 항목으로 **월말 예상 잔액**을 계산합니다.

- 꾹 누르면 정리 모드(살랑살랑), 끌어서 순서 변경, **겹쳐서 묶음 만들기**, 이름 추천 카드.

### ☁️ 동기화 · ⚙️ 설정 · ❓ 가이드
- **구글 계정으로 연결** → 폰과 PC에 똑같이 (할 일·가계부는 드라이브 숨김 폴더, 일정은 구글 캘린더). 항상 자동으로 맞추고, 배터리를 아끼고 싶으면 **절약 모드**만 켜면 됩니다.

- 설정: 진동(폰에서만)·알림 켜고 끄기. PC에는 소리·진동이 없습니다.

## 3. 사용 방법

### 인터넷에서 바로 쓰기
**https://crowtit517.github.io/damdanote/** 를 열면 됩니다. PC 크롬은 주소창의 **설치** 아이콘, 폰 크롬은 **⋮ → 앱 설치(홈 화면에 추가)**로 앱처럼 쓸 수 있습니다.

### 내 PC에서 실행 (개발용)
빌드 과정이 없습니다. 폴더에서 아래 한 줄이면 됩니다.

```bash
python -m http.server 5500
```

브라우저에서 **http://localhost:5500** 을 엽니다. (ES Modules를 쓰기 때문에 파일을 더블클릭해서 열면 동작하지 않습니다.)

### PC 앱 (exe)
`desktop/` 폴더에서 `npm install` → `npm run build` 하면 설치 파일 `desktop/dist/Damda-Setup.exe`가 만들어집니다. 실행하면 바로 설치되고 바탕화면에 **담다** 바로가기가 생깁니다. 서명하지 않은 파일이라 Windows 경고가 뜨면 **추가 정보 → 실행**을 누르세요. 개발할 때는 `npm run dev`.

### 앱처럼 설치 (PWA)
크롬 주소창 오른쪽의 **설치** 아이콘을 누르면 바탕화면 앱처럼 열립니다. 인터넷이 없어도 열립니다.

### 처음 쓰는 순서
1. 왼쪽 위 **☰** 에서 캘린더 · 할 일 · 가계부를 고릅니다.
2. 할 일과 지출을 적습니다. 기록은 먼저 **이 기기**에 저장됩니다.
3. 여러 기기에서 쓰려면 ☰ → **구글 계정으로 연결** (계정 고르기 → 처음 한 번 허용). 캘린더도 함께 연결되어 폰 캘린더 일정이 보입니다.
4. 모르는 것은 오른쪽 위 **?** → 그림 가이드.

> 🔐 구글 연결은 현재 **테스트 모드**라 등록된 테스트 사용자만 로그인할 수 있습니다. 직접 운영하려면 자신의 OAuth 클라이언트 ID를 `js/config.js`에 넣으세요. 절차는 [docs/data-sync.md](docs/data-sync.md) 8장.
> 웹은 로그인이 약 1시간마다 갱신됩니다(다음 클릭에 자동, 창이 잠깐 깜빡임). 폰의 갤럭시 앱(Phase 5)은 계속 유지됩니다.

## 4. 설계 원칙

| 원칙 | 구체적으로 |
|---|---|
| **단순하고 가볍게** | 프레임워크·빌드 도구·npm 의존성 0개. 순수 HTML/CSS/JS(ES Modules). 차트도 직접 그린 SVG |
| **기기 먼저 (local-first)** | 모든 기록은 먼저 기기(IndexedDB, 바뀐 항목만 저장)에 → 인터넷이 없어도 동작. IndexedDB를 못 쓰면 localStorage로 대체, 저장이 실패해도 화면은 정상 |
| **서버 없음** | 할 일·가계부는 사용자의 구글 드라이브 **앱 전용 숨김 폴더**(`drive.appdata`), 일정은 사용자의 **구글 캘린더**. 운영자가 보관하는 데이터가 없음 |
| **최소 권한** | 드라이브는 앱 전용 폴더만(다른 파일은 볼 수 없음), 캘린더는 일정 보기·고치기만. 추가 계정은 캘린더 권한만 |
| **나눠서 저장** | 일정만 구글 캘린더와 주고받고, 할 일·가계부는 담다에만. 공유 캘린더로 돈 정보가 새지 않게 |
| **금융 연동 금지** | 은행·카드·결제 연동 코드는 어떤 형태로도 넣지 않음. 금액·날짜·메모만 |
| **지워도 되돌릴 수 있게** | 실제 삭제 대신 `deleted: true` + 모든 항목에 `updatedAt` → 되돌리기와 기기 간 병합이 안전 |
| **모두를 위한 화면** | 모든 창은 ✕·바깥 클릭·Esc·뒤로가기로 닫힘, 밝은/어두운 화면, 폰 크기 대응, 움직임 줄이기 설정 존중 |

## 5. 구조

```mermaid
flowchart LR
  subgraph A["💻 PC (크롬 PWA)"]
    UA[화면] --> SA[(기기 저장소)]
  end
  subgraph B["📱 폰 (브라우저 → 갤럭시 앱 예정)"]
    UB[화면] --> SB[(기기 저장소)]
  end
  SA <-->|"할 일·가계부: 저장 후 1초 올림 · 5초마다 확인"| D[("구글 드라이브<br/>앱 전용 숨김 폴더<br/>damda-data.json")]
  SB <-->|"버전 확인 → 항목별 병합"| D
  SA <-->|"일정: 추가·수정·삭제 · 1분마다 받기"| C[("구글 캘린더")]
  SB <--> C
  C <--> P["📱 갤럭시 · 노션 캘린더"]
```

**캘린더 동기화** (`js/sync/gcal.js`)
- 보고 있는 달 ± 1달을 받아 기기에 보관합니다. 인터넷이 없어도 보입니다.
- 담다에서 바꾼 일정은 **보낼 목록(outbox)**에 넣고 순서대로 보냅니다. 새 일정은 아이디를 미리 정해서 다시 보내도 하나만 생기고, 고칠 때는 **버전(etag)을 확인**해서 다른 곳에서 먼저 고친 일정을 덮어쓰지 않습니다.
- 가짜 구글 캘린더·드라이브 서버로 검증했습니다 (메뉴·담는 곳 17, 캘린더 18, IndexedDB 15). 추가·알림, 오프라인 후 1개만 생성, 충돌, 지우기·되돌리기, 보기만, 두 번째 계정, 자동 옮기기·중복 없음, 계정별 할 일·가계부 등.

**동기화 엔진** (`js/sync/engine.js`)
- 드라이브 파일의 **버전이 바뀌었으면** 받아서 항목마다 `updatedAt`이 더 최신인 쪽을 남깁니다.
- 올리기 직전에 **버전을 한 번 더 확인**해 다른 기기의 변경을 덮어쓰지 않습니다.
- 로그인 만료(약 1시간)는 "다시 로그인 필요"로 알리고, 그동안의 기록은 기기에 그대로 남습니다.
- 가짜 드라이브로 두 기기 상황을 흉내 내 검증했습니다: 첫 업로드, 1초 자동 올림, 다른 기기 변경 약 3초 안에 받기, 동시 수정 둘 다 유지, 삭제 전파, 연결 끊기 후 기록 유지.

## 6. 개발 과정: 묻고, 정하고, 고쳤다

담다는 **기획자(사용자)가 묻고 결정하고, AI가 설명하고 구현하는** 방식으로 만들었습니다. 모든 요청과 결정은 [PLAN.md](PLAN.md)에 남겨 두었습니다.

```
 ① 질문·아이디어  →  ② 선택지와 장단점 설명  →  ③ 사용자가 결정
        ↑                                              ↓
 ⑥ 피드백 ←  ⑤ 실제 화면으로 확인  ←  ④ 문서 기록 → 구현
```

| 알림 소리 | *소리도 굳이 필요할까* | 폰 기본 알림음만, **PC는 소리·진동 없음** |

| 구글 캘린더 읽기만 연결 | *연동하면 자동으로 서로 다 수정 가능하게* | **자동 양방향 동기화** (일정만, 할 일·가계부는 담다에만) |
| 캘린더 연결 버튼·옮기기 질문 | *노션이랑 구글 캘린더처럼 자동으로* | 계정 연결 = 캘린더 연결, 예전 일정도 **저절로** 옮기기 |
| 화면 제목의 이모지 | *모바일이든 PC든 빼줘* | 제목·메뉴를 글자만으로 깔끔하게 |
| PC 위젯 자리 버튼 3개 | *이것들 굳이 필요할까?* | 늘 바탕화면에 고정, 버튼 없앰 |
