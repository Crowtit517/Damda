# 화면 설계

> PLAN.md의 하위 문서. **사용자가 보기에 읽기 쉬운가**를 기준으로 설계한다.

## 1. 화면 구성: 화면 3개(☰ 메뉴로 이동) + 하루 통합 패널

기능별로 **따로 보는 화면**(캘린더·할 일·가계부)과, 그날의 모든 것을 **한 번에 보는 화면(통합 패널)**을 둘 다 둔다. 데이터는 같고 보여주는 방식만 다르다. 할 일 목록, 지출 목록 같은 부품은 탭과 패널이 **같은 코드**를 쓴다.

```
┌ ☰  📅 캘린더              ● 이 기기에 저장    🌙 ┐   ← 제목 = 지금 보고 있는 화면
│                                                │
│   [지금 화면]                                    │      (탭 줄은 없음. ☰ 메뉴에서 이동)
│                                                │
└────────────────────────────────────────────────┘
```

| 화면 | 목적 | 이럴 때 쓴다 |
|---|---|---|
| 📅 캘린더 | 한 달 훑어보기 | "이번 달에 뭐가 있지?" |
| ✅ 할 일 | 하루 할 일 관리 (참고 이미지 "My Tasks" 그대로) | "오늘 뭐 해야 하지?" |
| 💰 가계부 | 하루 지출 기록, 이번 달 합계 | "오늘 얼마 썼지?" |
| 하루 통합 패널 | 캘린더에서 날짜를 누르면 스르륵 나옴. 그날의 일정·할 일·지출을 한 번에 | "이날 무슨 일이 있었지?" |

**읽기 쉬운 화면을 위한 원칙**
- 한 화면에는 목적이 하나다. 탭이 바뀌면 화면 전체가 그 목적에 맞게 바뀐다.
- 가장 중요한 숫자(진행률, 지출 합계)는 크게, 맨 위에 둔다.
- 색만으로 구분하지 않는다. 카테고리는 색과 글자 배지를 함께 쓴다.
- 비어 있는 화면에는 "아직 기록이 없어요"와 바로 입력할 곳을 보여준다.
- 앱을 열면 마지막에 보던 탭이 열린다. 할 일과 가계부 탭은 항상 **오늘** 날짜로 시작한다.

## 2. 📅 캘린더

```
  2026년
  ‹  [10월 ▾]  ›        (오늘)   ← (오늘)은 이번 달이 아닐 때만 보임
  일 월 화 수 목 금 토
  날짜 칸: ● 일정 점  ✓ 2/5  -12,000
```
- ‹ ›는 **월 단위**로 이동한다. 연도 표기도 함께 바뀐다.
- [10월 ▾]를 누르면 선택 창이 열린다: 연도 ‹ 2026 ›, 1~12월 칸, [오늘로].
- 날짜 칸 표시 우선순위: 일정 점 > 지출 > 할 일. 모바일에서 할 일 진행은 숨긴다.
- 날짜 칸을 누르면 **하루 통합 패널**이 열린다.

## 3. ✅ 할 일 (참고 이미지 기준)

- 맨 위: `‹ 10월 3일 (토) ›` 날짜 이동, 날짜를 누르면 날짜 선택
- 진행률 카드: 전체 `완료/전체 (퍼센트)` + 막대, 남은 할 일 수, 업무·개인·공부별 카드
- 오늘 화면에서 이전 날짜에 못 끝낸 할 일이 있으면: "밀린 할 일 N개 → 가져오기"
- 입력: 카테고리 칩 + 입력창 + 추가 (`Alt+N`으로 입력창 이동, Enter로 추가)
- 카테고리는 8장(v2) 규칙: 칩으로 고르고, 진행률 카드·필터 칩에는 그날 쓴 카테고리만 나온다.

### 3-1. 반복 할 일 (예: 매일 약 먹기 — 아침·저녁)
```
[반복할 일 (예: 약 먹기)] [반복] [추가]
  반복:   [매일] [요일 선택] [매월]           요일 선택 → (월)(화)(수)(목)(금)(토)(일)  (평일은 월~금 선택)
  하루에: [1번] [2번] [3번]   → 2번: 아침·저녁 / 3번: 아침·점심·저녁 (이름은 고칠 수 있고, 고친 이름은 횟수를 바꿔도 유지)
  기간:   [반복] [기한]        반복 = 오늘부터 멈출 때까지
          기한 → 시작 [📅 10-05] ~ 끝 [📅 10-11]   "📅 10월 5일 ~ 10월 11일 · 7일"
          (끝이 시작보다 빠르면 시작에 맞춰주고, 끝을 비우면 안내)

☐ 약 먹기 (아침)   매일 · 🔥 5일 연속   [건강] ⋯ ✕
```
- 해당하는 날에만 목록에 나타난다. 진행률·카테고리 카드·달력 칸 숫자에도 포함된다.
- **🔥 연속 기록**: 해당하는 날마다 모든 회차를 체크한 날이 며칠 이어졌는지 (오늘을 아직 안 했으면 어제까지로 셈, "이 날만 삭제"한 날은 건너뜀)
- ✕ 삭제 → **[이 날만] / [이 날부터 앞으로 전부]** 중 선택. "이 날만"은 되돌리기 가능
- ⋯ 버튼 → 수정 창: 이름, 카테고리, 반복, 회차, 기간, [이 날부터 그만하기]. 바꾸면 아직 체크하지 않은 날에 적용
- 반복 할 일은 "밀린 할 일 가져오기"에 넣지 않는다 (매일 약이 쌓이면 안 되므로)
- 알림(아침 9시 "약 드세요")은 Phase 5에서 구글 캘린더 반복 일정으로 연결 (지금은 없음)
- 필터 칩: `전체 N` `업무 N` `개인 N` `공부 N`, 오른쪽에 [완료 항목 삭제]
- 목록: 왼쪽 카테고리 색 테두리, 체크박스, 제목, 카테고리 배지, ✕ 삭제
- 참고 이미지에서 뺀 것: "N일 전" 상대 시간, 정렬 옵션 (하루 단위라 불필요)

## 4. 💰 가계부 (토스 느낌의 통계 화면)

```
  [ 월 | 년 ]          ‹ 2026년 10월 ›
  10월 지출
  1,284,000원                         ← 가장 크게
  ▲ 지난달 같은 기간보다 82,000원 더 썼어요 (6.8%)
  ── 이번 달 누적 (진한 선)  ── 지난달 (흐린 선)   ← 선 그래프, 누르면 그날 금액
  수입 3,200,000원 · 지출 1,284,000원 · 남은 돈 1,916,000원
  카테고리별: 🟦 식비 ████ 420,000원 33% ...
  ── 날짜별 기록 ──  ‹ 10월 3일 › [지출|수입] 카테고리 금액 메모 추가
```
- **월 보기**(기본): 이번 달 누적 지출 선 vs 지난달 선. 비교는 **같은 날짜까지** (3일이면 지난달 1~3일과)
- **년 보기**: 월별 막대(올해 진하게, 작년 흐리게). 막대를 누르면 그 달의 월 보기로. 비교는 작년 같은 기간과
- 증감은 글자와 화살표로 표시한다 (▲ 더 씀, ▼ 덜 씀). 색만으로 구분하지 않는다.
- 수입은 직접 입력하는 숫자다 (금융 연동 아님).
- 기록이 없으면 그래프 자리에 "기록이 쌓이면 여기에 그래프가 그려져요"를 보여준다.

### 4-1. 고정 수입·지출 (매월 반복)

**목록 카드**
```
고정 수입·지출                      [＋ 추가]
  [매달 수입 +320만] [매달 지출 -59.5만] [고정 후 남는 돈 260.5만]
  이번 달 기록  ████░░░░  2/4
  ─────────────────────────────────────────
  1일   월세        [✓ 기록됨]         -550,000
  2일   관리비      [금액 입력 필요]       미정
  25일  월급        [D-22 예정]      +3,200,000
  말일  통신비      [일시정지]          -45,000
```
- **아담한 버전 (10-04)**: 수입·지출을 나누지 않고 날짜순 한 줄 목록. 금액 색(수입 파랑·지출 빨강)으로 구분. 추가 버튼은 제목 옆.
- 금액이 매달 다른 항목은 위 합계에서 빼고 "N개는 합계에서 빠져 있어요"라고 알려준다.

**설정 창**
- 종류: [지출 | 수입] (지출은 빨강, 수입은 파랑으로 선택 표시)
- **자주 쓰는 항목** = 가계부 카테고리 칩 (8장). 누르면 이름(비어 있을 때), 기억해 둔 종류·날짜·금액이 채워진다.
- 이름 · 금액, "매달 금액이 달라요 (그날 금액을 물어보기)"
- **매월 며칠**: 1~31 칸 + 말일 (7칸 달력 모양)
- **미리보기 문장**: "매월 25일에 월급 3,200,000원이 수입으로 기록돼요 · 다음 기록: 10월 25일 (D-22)"
- 이번 달 날짜가 이미 지났으면 "이번 달 N일분도 지금 기록하기" (기본은 다음 달부터)

**동작**
- 그날이 되면 자동으로 기록되고 "고정" 표시가 붙는다. 기록을 누르면 금액·메모를 고칠 수 있다 (다음 달 설정은 그대로).
- "금액 확인" 항목은 그날 가계부 맨 위에 "📝 관리비 금액을 입력해주세요 [금액] [기록] [이번 달 건너뛰기]".
- 월 보기(이번 달)에 아직 안 들어온 고정 항목을 예정으로 계산해 "월말 예상 남은 돈"을 보여준다.
- 일시정지 → 다시 시작하면 멈춘 동안의 달은 기록하지 않는다. 삭제해도 이미 기록된 내역은 남는다. 31일이 없는 달은 말일.

## 5. 하루 통합 패널

| 항목 | PC | 모바일 |
|---|---|---|
| 모양 | 오른쪽 **사이드 패널** | 아래에서 올라오는 **바텀시트** (화면 약 85%) |
| 달력 | 그대로 보이고 클릭 가능. 다른 날짜를 누르면 패널 내용만 바뀜 | 뒤에 흐리게 |
| 닫기 | ✕, Esc, 뒤로가기 | ✕, 바깥 클릭, 손잡이를 아래로 끌기, 뒤로가기 |

- 내용: 날짜와 ‹ › 이동 → 요약(진행률, 이날 지출, 카테고리별) → 📅 일정 → ✅ 할 일 → 🪙 가계부
- **패널은 가볍게 (보기·체크 위주)**:
  - ✅ 할 일: **체크리스트만** (체크·해제). 추가·삭제·반복 설정은 없음 → [할 일에서 추가·편집 ›]을 누르면 **할 일 탭의 그 날짜**로 이동
  - 💰 가계부: 그날 지출·수입 합계와 기록 최대 4개만 읽기 전용으로 → 누르거나 [가계부에서 기록하기 ›]를 누르면 **가계부 탭의 그 날짜(그 달)**로 이동
  - 📅 일정: 지금처럼 패널에서 추가·삭제
- 섹션은 접었다 펼 수 있다.
- 일정 입력: 제목, 시작일~종료일, 시간(비우면 종일), 색 (1차는 기기 기본 날짜·시간 입력창 사용)
- 0.25초 정도 부드럽게 미끄러진다. 기기의 "동작 줄이기" 설정이 켜져 있으면 바로 나타난다.

## 6. 창 닫기 공통 규칙

**모든 패널, 선택 창, 모달**에 똑같이 적용한다. 여닫는 코드는 `js/ui/overlay.js` 한 곳에 모은다.

| 닫는 방법 | 동작 |
|---|---|
| ✕ 버튼 | 항상 오른쪽 위 |
| 바깥(어두운 배경) 클릭 | 닫힘. **PC 사이드 패널은 예외** (배경이 없고, 달력을 누를 수 있음) |
| `Esc` / 안드로이드 뒤로가기 | **맨 위 창부터** 하나씩 닫힘. 앱이 꺼지지 않음 |
| 같은 층의 다른 창을 열 때 | 이전 창은 자동으로 닫힘 |
| 창 위에 창 (예: 고정 항목 창 → 카테고리 관리) | **나중에 연 창이 항상 위**. 위에 열린 창의 배경은 옅게 해서 화면이 두 겹으로 어두워지지 않게 |

- 원본 달빛달력의 날짜·시간 선택 창이 닫히지 않던 원인: CSS의 `display: flex`가 `hidden`을 덮어씀 → 전체 CSS에 `[hidden] { display: none !important; }`를 처음부터 넣는다.
- 원본에서 날짜를 고르기 전 제목이 "-"로 보이던 문제 → 처음부터 오늘 날짜를 표시한다.

## 7. 편의 기능

- **삭제 → 실행 취소**: 지우면 몇 초간 "삭제됨 · 되돌리기"가 뜬다. 완료 항목 일괄 삭제만 확인 창을 쓴다.
- **카테고리 삭제도 되돌리기**: 확인 후 지우면 "'식비' 카테고리를 삭제했어요 · 26개는 미분류로 [↺ 되돌리기]"가 8초간 뜬다. 누르면 카테고리와 원래 연결이 한 번에 돌아온다 (그 사이 다른 카테고리로 직접 바꾼 항목은 그대로 둔다).
- 알림(토스트)은 둥근 알약 모양, 살짝 튀어 오르며 등장. 되돌리기가 있으면 동그란 버튼과 남은 시간 막대를 보여준다.
- 키보드: `←` `→` 이동(캘린더는 월, 할 일·가계부는 하루), `Esc` 닫기, `Alt+N` 할 일 입력
- 앱을 켜둔 채 자정이 지나면 "오늘" 표시가 자동으로 바뀐다.
- 테마: 기기 설정을 따르고 🌙/☀️ 버튼으로 바꾼다. 다크 = 달빛달력 남색, 라이트 = 참고 이미지 보라색
- **☰ 메뉴** (왼쪽 위, 왼쪽에서 열리는 서랍): ① 화면 선택(캘린더·할 일·가계부) ② 동기화: 구글 계정으로 연결 / 다시 로그인 / 지금 맞추기 / 연결 끊기, 방식 고르기 — 이 기기에만 / 자동 동기화(추천, 저장 후 1초·보는 동안 5초) / 절약 모드(열 때·돌아올 때) / 직접([지금 맞추기]). **백업(JSON)은 없앴다** — 구글 드라이브가 보관한다.
  - **10-05 정리**: ① 화면 ② 동기화(연결 전: [구글 계정으로 연결] + "연결 전에는 이 기기에만 저장돼요" / 연결 후: 상태, 자동 동기화 설명 한 줄, 절약 모드 스위치, 절약 모드일 때만 [지금 맞추기]) ③ 구글 캘린더(기본 계정 캘린더 켜고 끄기, 추가 계정은 "다른 계정 N개 ▾"로 접힘 — 메뉴를 열 때마다 접힘, [＋ 다른 구글 계정 추가]) ④ [⚙️ 설정] 버튼 → **설정 창**(화면 위쪽 작은 창): 일정 담는 곳·할 일·가계부 담는 곳(계정이 하나여도 항상 보임, 연결 전에는 안내 문구), 진동·알림, 맨 아래 [구글 연결 끊기]
  - ③ **설정**: 📳 진동(폰에서만 보임, 꾹 누르기·옮기기 반응) / 🔔 알림(일정·반복 할 일). 소리 설정은 없음 — 폰 기본 알림음. PC는 소리·진동 없음. 기기마다 따로 저장
- 오른쪽 위 표시(누르면 메뉴): "이 기기에 저장" / "구글 연결 대기" / "맞추는 중…" / "동기화됨 · 3분 전" / "다시 로그인 필요" / "동기화 오류"
- **? 사용 가이드** (테마 버튼 왼쪽, `js/parts/guide.js`): 주제 7개 × 그림 카드(그림 + 반짝이는 곳 + 짧은 문장, 초등학생도 알아볼 쉬운 말). 다음 › / 밀어서 넘기기. 지금 화면의 주제부터 열린다. 기능이 바뀌면 가이드 내용도 같이 고친다
- **💰 금액 보기 스위치** (캘린더 화면, 달 이동 줄 오른쪽): 끄면 캘린더 칸의 지출 금액과 날짜 패널의 돈 정보(이날 지출·가계부 요약)를 숨긴다. 가계부 화면은 그대로. 기기마다 따로(`ple-set-money`), 처음은 켜짐. ? 버튼과 떨어뜨려 잘못 누르지 않게

- **날짜 패널 일정** (10-05): 구글 일정은 G 표시(누르면 구글 캘린더에서 열기). 고칠 수 있는 일정은 눌러서 고치기 창(제목·날짜·시간·끝 시간·알림·색, 지우기), ✕는 8초 되돌리기. 반복 일정·공휴일은 보기만. "일정 추가"는 구글에 연결돼 있으면 구글 캘린더에 저장

## 8. 카테고리 (홈 화면 방식)

목록은 두 개다: **할 일 카테고리**, **가계부 카테고리**(지출·수입 공통, "자주 쓰는 고정 항목"도 겸함). 정리하는 창을 따로 두지 않고, **쓰는 자리(칩 줄)에서 그대로 정리**한다. 갤럭시 홈 화면의 앱 폴더와 같은 방식.

**① 칩 줄 (평소)**
```
  ●○ 건강 2   ●● 회사 2   ○ 공부   ○ 독서
  ○ 청소   [＋9]   [＋ 추가]                    ← 최대 2줄, 넘치면 [＋N]
```
- **묶음**은 칩 하나로 접혀 있다. 폴더 모양 대신 안에 든 카테고리의 **색 점(2×2)**이 미리 보인다.
- 묶음을 누르면 그 자리에서 아래로 펼쳐지고, 안의 칩을 고르면 묶음 칩에 "건강 › 약"으로 표시된다.
- 옆 스크롤 없이 **최대 2줄**. 넘치면 [＋N] (화면 폭에 맞춰 자동 계산, 고른 칩은 숨기지 않음).
- 처음엔 비어 있다 (가계부는 예시 카테고리만 "예시"로).

**② 서랍 (아래에서 올라오는 공간, PC는 가운데)**
- [＋N]이나 [＋ 추가]를 누르면 열린다. 묶음별 구역 + "묶지 않은 것", 위아래 스크롤. 15개가 넘으면 🔍 검색칸.
- 고르면 닫히고 칩 줄에 반영. [＋ 추가]로 열었으면 아래 입력칸에서 새로 만들고 바로 선택된다.
- 고정 항목 창 같은 창 위에서도 맨 위에 열린다.

**③ 정리 모드**
- 칩·묶음·카드·배지를 **꾹 누르면**(PC는 우클릭) 서랍이 정리 모드로 열린다. 서랍의 [정리하기]로도 들어간다. [완료]로 끝.
- 칩이 홈 화면처럼 살짝 흔들리고, 오른쪽 위에 ×가 붙는다.
- **칩을 끌어 다른 칩 위에 겹치면 묶음이 생긴다** (받는 칩이 부풀어 표시). 칩 가장자리에 놓으면 순서만 바뀐다.
- 묶음 밖("묶지 않은 것")으로 끌면 꺼내지고, **비게 된 묶음은 저절로 사라진다.**
- 묶음 머리줄을 끌면 묶음끼리 순서가 바뀐다. [풀기]를 누르면 묶음만 없어지고 카테고리는 밖으로 (되돌리기 있음).
- 칩을 누르면 위에 **고치기 카드**: 이름, 색(색 없음 + 8색), 삭제. ×나 삭제는 바로 지우고 8초 동안 [↺ 되돌리기] (그 때문에 사라진 묶음도 함께 복구).
- **새 묶음 이름**: 기계적인 "새 폴더" 대신, 안에 든 이름으로 자동("운동·약") 붙이고 "✨ 새 묶음이 생겼어요. 이름을 붙여볼까요?"를 묻는다. 추천 칩(할 일: 건강·회사·공부·생활·취미·집안일 / 가계부: 고정비·생활비·식비·수입·저축·여가)을 누르거나 직접 입력, [나중에]도 가능.

**색**: 사용자가 고른다 (색 없음 + 검증된 8색). 점·칩·배지에는 반전 테두리 (라이트 검정 / 다크 흰색). 그래프 막대에는 테두리 없음.

**기타**
- 하루 화면의 진행률 카드·할 일 필터에는 **그날 쓴 것만**. 할 일 필터에는 묶음도 나온다 (누르면 그 묶음의 할 일을 모아 봄).
- 종류별 30개까지. 묶음 안에 묶음은 없다 (한 단계).
- 고정 항목을 저장하면 그 가계부 카테고리에 설정을 기억하고, 고정 항목 창에서 그 칩을 누르면 자동으로 채운다. 이미 등록된 칩에는 ✓.
- 카테고리 관리는 메뉴에 두지 않는다 (☰ 메뉴는 화면·동기화·백업).

## 9. PC 앱 화면 (10-05, `desktop/` · `html.desk-app`일 때만)

- **창 전체가 곧 앱**: 보라 배경·둥근 판 없음, 구역은 얇은 선. 담다 위쪽 줄(☰ · 제목 · 동기화 · ? · 테마)이 제목 줄 역할, 오른쪽 끝에 — □ ✕만 (색은 밝게/어둡게 따라감). 최소 창 960×600

  - 경계를 끌어 넓이 조절: 300px 이상, **창의 1/3 이하** (캘린더 2/3 이상). 기본 30%, 정한 넓이 기억
